# Artificial Intelligence Notebooks

A collection of introductory notebooks on data analysis, supervised learning, the perceptron, and simple linear regression.

## Learning path

[`machine-learning/learning-path/`](machine-learning/learning-path/README.md) is a self-study route through machine learning, organized by topic. Each module has a study guide and a notebook with demos and exercises, and links to the topic notebooks in this repo.
